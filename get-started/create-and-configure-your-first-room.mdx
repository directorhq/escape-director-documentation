Use this guide to create a Room and set its starting time and Clue count. Rooms
live in **All Rooms**.

## Create the Room

1. In **All Rooms**, select **Create Room**.
2. Enter a Room name your staff will recognize, the starting time in minutes,
   and **Clues per game**.
3. Select **Create Room**.

<Frame caption="After creation, the Details tab keeps Room defaults and all three player-facing screen configurations together.">
  <img src="/images/room-editor-details.png" alt="Escape Director Room editor showing the consolidated Details tab, save status, Live View screen controls, and preview" />
</Frame>

These values are the normal starting state. The Game Master can adjust time and
reported Clues during a game.

## How saving works

Changes on **Details** and **Puzzles & clues** save on their own, and the top
of the page shows **Saved** when they have. **Undo** (or Ctrl+Z) takes back the
last saved change, one at a time, and **Redo** puts it back. Undo lasts until
you leave the page. Automations and Devices save only when you select **Save**.

## Delete a Room

<Danger>
Deleting a Room is permanent. It deletes the Room's Puzzles, Clues, media, Automations, and every game played in it. Its games leave Room Statistics, Analytics, and Leaderboards. Edit the Room instead unless you want all of this gone.
</Danger>

You need a connection to delete a Room. If the Room Station still has finished games waiting to sync, reconnect and let them sync first.

1. In **All Rooms**, select **⋮** (Room actions) on the Room, then **Delete room**.
2. Type the Room name to confirm, then select **Delete room**.
