A Room holds everything for one escape room: its Puzzles, Clues, Live View, media, Automations, and Devices. Create and open Rooms from **All Rooms**.

## Create the Room

1. In **All Rooms**, select **Create Room**.
2. Enter a Room name your staff will recognize, the starting time in minutes, and **Clues per game**.
3. Select **Create Room**.

The starting time and Clue count are where each game begins. During a game, the Game Master can still change the time and the Clues used.

## How Room changes save

- **Details** and **Puzzles & clues** save on their own. The top of the page shows **Saved** when they have.
- **Undo** (or Ctrl+Z) takes back the last saved change, one at a time. **Redo** puts it back. Undo history lasts until you leave the page.
- **Automations** and **Devices** save only when you select **Save**.

## Delete a Room

<Danger>
Deleting a Room is permanent. It deletes the Room's Puzzles, Clues, media, Automations, and every game played in it. Those games also leave Room Statistics, Analytics, and Leaderboards. If you only want to change the Room, edit it instead.
</Danger>

You need an internet connection to delete a Room. If the Room Station has finished games waiting to sync, reconnect and let them sync first.

1. In **All Rooms**, select **⋮** (Room actions) on the Room, then **Delete room**.
2. Type the Room name to confirm, then select **Delete room**.
