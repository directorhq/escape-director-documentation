Puzzles are the challenges in a Room. Each Puzzle has Clues, in order, that the Game Master can send. Edit them in **All Rooms → Edit → Puzzles & clues**, or from the Room Dashboard during a game.

## Add a Puzzle

1. Select **Puzzle** at the bottom of the Puzzle list and enter a short name.
2. Add the answer and a short staff description if they help the Game Master.
3. Add Clues in order, from a light nudge to direct help. To attach an image, audio, or video from the Media library, use the buttons beside **Clue**.

Changes save on their own. If a change can't save yet, such as an empty Clue or a Puzzle with no name, the editor shows **Not saved yet** and the reason.

Tips:

- Order Puzzles the way players usually solve them.
- Write Clues for players. Keep staff notes in the Puzzle description.

## Group Clues in a Section

A Section holds Clues without adding a Puzzle to solve, so it doesn't count toward completed Puzzles. Select **Section** instead of **Puzzle** at the bottom of the list. To switch later, open **Puzzle options** and choose **Convert to Section** or **Convert to Puzzle**.

## Edit Puzzles and Clues from the Room Dashboard

You can add and edit Puzzles and Clues from the Room Dashboard, even during a game.

- **Puzzle:** select **+** at the top of the Puzzles list. To edit one, select **Edit Puzzles**, then **Edit Puzzle** from the Puzzle's actions. For a Clue Section, turn off **Can be marked complete**.
- **Clue:** select the Puzzle, then **+** at the top of the Clues list. Choose **Text**, **Image**, **Audio**, or **Video**, type the text or choose a file from **Room media**, and select **Create Clue**. To edit or reorder Clues, select **Edit Clues**.

How the Room Dashboard differs from the Room editor:

- If you change **Can be marked complete** during a game, the change applies from the next game.
- To delete a Puzzle, delete its Clues first. In the Room editor, deleting a Puzzle also deletes its Clues.
- A media Clue can use only a file already in the Media library.
- You can't add or edit Puzzles or Clues while the Room Dashboard is offline.

To upload new files, see [Manage Room media](/build-your-rooms/manage-room-media).

<Warning>
Deleting a Puzzle deletes its Clues. Deleting a Media library file deletes every Clue that uses it. Past Room Sessions don't change. Read the confirmation before you continue.
</Warning>
