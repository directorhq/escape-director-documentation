# Add Puzzles and Clues

Use this guide to give Game Masters a clear, ordered Room flow.

## Open the editor

1. Open **All Rooms**.
2. Select **Edit** for the Room.
3. Open **Puzzles & clues**.

<figure><img src="../.gitbook/assets/puzzles-and-clues.png" alt="Puzzles and clues editor for The Curator's Vault showing ten named Puzzles and the selected Counterfeit Seal Clue ladder"><figcaption><p>The Puzzle rail stays visible while you edit one Puzzle and its Clue ladder.</p></figcaption></figure>

## Add a Puzzle

1. Select **Puzzle** at the bottom of the Puzzle list.
2. Enter a short operational name.
3. To group Clues without adding a Puzzle to solve, select **Section** instead of **Puzzle**. You can switch later from **Puzzle options** with **Convert to Section** or **Convert to Puzzle**.
4. Add the answer or solve condition when staff needs it.
5. Add a brief internal description only when it helps the Game Master.
6. Add Clues in escalation order, from a light nudge to direct help.
7. Select **Apply changes**.

Use the attachment actions beside **Clue** to add an image, audio, or video Clue from the Room's Media library.

## Edit Puzzles and Clues from the Room Dashboard

You can also add and edit Puzzles and Clues from the Room Dashboard, even during a game.

### Add or edit a Puzzle

1. Select **+** (Add Puzzle) at the top of the Puzzles list, or select **Edit Puzzles** and then **Edit Puzzle** from a Puzzle's actions.
2. Enter the name, and the answer and description if staff need them.
3. Turn **Can be marked complete** off for a Clue Section.
4. Select **Create Puzzle** or **Save changes**.

During a game, a change to **Can be marked complete** applies to the next game. On the Room Dashboard, you can delete a Puzzle only after you delete its Clues. In the editor, deleting a Puzzle also deletes its Clues.

### Add a Clue from the Room Dashboard

1. On the Room Dashboard, select the Puzzle.
2. Select **+** (Add Clue) at the top of the Clues list.
3. Choose a **Content type**: **Text**, **Image**, **Audio**, or **Video**.
4. Type the Clue text, or choose the file from **Room media**.
5. Select **Create Clue**.

A media Clue can only use a file that is already in the Room's Media library. To add a new file, upload it first in [Manage Room Media](manage-room-media.md). To edit or reorder Clues, select **Edit Clues**. You can't add or edit Puzzles or Clues while the Room Dashboard is offline.

## Arrange the Room flow

- Reorder Puzzles to match the normal solve sequence.
- Use Clue Sections to group related Clues without increasing the completed-Puzzle count.
- Reorder Clues so Game Masters can increase assistance gradually.
- Remove duplicates and old instructions.
- Use player-facing Clue text; keep internal operating notes in the Puzzle description.

{% hint style="warning" %}
Deleting a Puzzle removes its current Clues but does not rewrite completed Room Session history. Deleting a Media library file that is attached as a Clue also deletes each linked media Clue; review the confirmation before continuing.
{% endhint %}

## You're ready when...

Every Puzzle has a recognizable name, the intended solve-tracking setting, the useful answer or description, and only the Clues staff may send during a game.
