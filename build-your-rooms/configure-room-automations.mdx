An Automation runs an ordered list of Actions when its Trigger happens, such as
all Puzzles being completed, a prop signal, or a Dashboard button. Set them up in
**All Rooms → Edit → Automations**.

Before you begin, set up every Puzzle, Clue, and media file the Automation will
use, and finish or reset any running game.

## Create an Automation

1. Select **New automation** and enter a name that tells the Game Master what it
   does.
2. Choose the Trigger.
3. Add each Action in running order. Drag an Action to change the order.
4. Select **Save** when the editor shows **Valid**.

New Automations start disabled. Choices that need Room content you haven't set up
are unavailable.

## Action order limits

- An Automation can have up to 20 Actions.
- Video and audio Actions move on to the next Action at once unless you turn on
  **Wait until finished before continuing**.
- **Complete Room** and **Fail Room** end the sequence; nothing can follow them.
  Put end-of-game media before them, or use the Room's success and failure
  screens.

## Enable and test the Automation

1. Turn on the Automation in **Edit Room**.
2. On the Room Station you use for games, start a test game from the Room
   Dashboard and cause the Trigger. For a Dashboard button, open
   **Automations**, select the button, then select it again while **Press
   again** shows.
3. Check the timer, Live View, audio, Puzzles, and Clues. The Session Log should
   show one Automation Run.
4. Select **Reset Room** before the next test or group.

<Warning>
The Room Dashboard does not have a preview or practice mode. Testing an Automation runs its real Actions and can change the timer, send Clues, play media, or complete or fail the Room.
</Warning>

## Prepare for offline operation

Enabled Automations and their media keep running during a game if the internet
drops, once the Room is ready offline. After you change an Automation or its
media, open the Room on its Room Station while online before relying on it
offline.
