The Media library holds a Room's images, audio, and video. You use them in Clues, in Live View, and to send during a game. Open it in **All Rooms → Edit → Media library**.

## Upload a file

Select **Upload**, choose an image, audio, or video file, and wait for the upload to finish.

<Frame caption="The Media library keeps every Room file searchable, and plays audio and video so you can check them before a game.">
  <img src="/images/room-images-library.png" alt="Room editor Media library showing All, Images, Audio, and Video filters, search, upload, and playable audio cards" />
</Frame>

Use filenames your staff will recognize, and avoid uploading near-copies. Play each audio and video file from its card before a game.

## Storage limits

Each Location adds 25 GB of media storage, and all your Rooms and Leaderboards share the total. One file can be up to 5 GB.

- To see how much you've used, open **Account Settings → Membership → Media storage**. It warns you when storage is nearly full.
- If an upload doesn't fit, Escape Director shows how much space it needs and how much is free. Delete media you no longer use, then try again.
- Deleting a file or a Room frees the space its media used.

## Where media is used

- **Live View:** the alert tone, soundtrack, background image or video, and intro video brief, set in the **Details** tab. See [Configure Live View](/build-your-rooms/configure-live-view).
- **Clues:** files attached in the Puzzle editor. See [Add Puzzles and Clues](/build-your-rooms/add-puzzles-and-clues).

Each file's label shows how many Room settings or Clues use it. **Library only** means nothing uses it, but Game Masters can still send it during a game.

To replace a file, upload the new one, then change each setting or Clue to use it.

## Delete a file

<Danger>
Deleting a file is permanent. Escape Director also removes it from Room screen settings and deletes the image, audio, or video Clues named in the confirmation. Past Room Sessions don't change.
</Danger>

Read every use listed in the confirmation before you delete.
