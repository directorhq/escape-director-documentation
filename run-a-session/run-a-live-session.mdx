---
title: "Run a live session"
description: Run one escape room game from the Room Dashboard: start the timer, send Clues, adjust time, track Puzzles, and save the Room Session.
---

The Room Dashboard is where a Game Master runs each game, from the first Clue to
the saved result. Before the first group, follow
[Prepare your Room Station](/prepare-for-a-shift/prepare-your-room-station).

## Start the game

1. Open **All Rooms**, choose the Room, and select the **Game Master**.
2. Select **Open Live View** and check the player screen.
3. Select the first Puzzle the group will meet.
4. When players are ready, select **Start** and check that the Live View timer
   counts down.

## Help players

- To send a Clue, choose the current Puzzle, then select the Clue. The Puzzle
  also shows its answer and description.
- To send your own words, use the message box.
- Select **+** in the Puzzles or Clues list to add a Puzzle or Clue during the
  game. See [Add Puzzles and Clues](/build-your-rooms/add-puzzles-and-clues#edit-puzzles-and-clues-from-the-room-dashboard).
- To send Room media, use **Images**, **Videos**, or **Audios**. Audio plays
  from the Room Station, so check its speaker and volume.
- Use **Mic** only if talking to players live is part of the Room.
- Change the Clue count if needed.

## Adjust time

To add time, type the number of minutes and select the **Minute(s)** button
beside it. A negative number takes time away. Use the speed controls only for
testing or a deliberate correction.

## Track Puzzle progress

When players solve a Puzzle, select **Mark Complete**. If you marked one by
mistake, undo the completion. The Session Log keeps both actions.

The **Session Log** records what happened. Its filter shows or hides **Sent to
players**, **Completions**, and **Clock changes**; the session start, time
adjustments, and outcome are always shown.

## End and save the Room Session

1. If the group escapes, select **Complete Room**. If the timer runs out, the
   game is saved as a failure.
2. In the Session details dialog, check the Game Master, the number of players
   and experienced players, the Clue count when shown, and any notes.
3. Save once. The game then appears in **Room Statistics**.

<Warning>
Don't close the Room Dashboard while a finished Room Session is still waiting to
save or sync. If saving is delayed, follow the recovery steps on screen.
</Warning>
