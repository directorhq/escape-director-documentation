---
title: "Troubleshoot a live session"
description: "Fix common problems during a live game, such as Live View not opening, media not playing, lost connection, or a Room Session that won't save."
---

Find the problem below. Whatever happens, keep the Room Dashboard open until the
Room Session is saved.

## Live View doesn't open

1. Check that the browser didn't block the new window.
2. Look in the taskbar and on other displays for a Live View window that is
   already open. Don't open several for the same Room.
3. If it opened on the wrong display, move it before using fullscreen.

## Live View is open but looks wrong

- Check that the correct Room is open.
- Exit fullscreen, move the window to the right display, and check its scaling
  and resolution.
- If the layout itself is wrong, [fix Live View](/build-your-rooms/configure-live-view)
  before the next group.

## A message or Clue doesn't appear

- Check that Live View is open and the correct Puzzle is selected.
- Check the Session Log before sending it again.
- **Clear Live View** removes what players currently see; use it only on purpose.

## Audio or media doesn't play

1. Check the Room Station's output device and volume.
2. Open the **Audio mixer** and check that the file exists and isn't muted.
3. Check that the browser is allowed to play or capture audio.
4. Try the control once more.

If a file is missing, send something else for now. Fix the Room before the
next group, not in the middle of a game.

## The timer is wrong

- Type the number of minutes (negative to take time away), then select the
  **Minute(s)** button. Check the new time on both the Room Dashboard and Live
  View.
- Don't use the speed controls during a real game.

## The Room Station loses its connection

- Keep the Room Dashboard and Live View open. Don't refresh or sign out.
- Continue only if the app shows the Room is available offline.
- When the connection returns, let any waiting Room Session sync.

## The Room Session doesn't save

1. Keep the completion dialog or recovery screen open.
2. Check every required field, including the Game Master and player details.
3. Submit once and wait for the result.
4. If the app says the record is pending or was rejected, leave the Room Station as it is and follow the recovery steps on screen.

<Danger>
Clearing browser data, removing the offline download, or discarding a pending or rejected Room Session deletes that game's record from this computer for good. Do it only if you mean to.
</Danger>

## An application update is ready during a game

Finish and save the current game first. **Update now** stays disabled while this
browser profile has an active game, including one in another Escape Director
window.

## Contact support

If these steps don't fix the problem, [contact support](/account-and-help/help). Include the Room name, the error you see, your browser and operating system, and whether the game is still running or waiting to save.
