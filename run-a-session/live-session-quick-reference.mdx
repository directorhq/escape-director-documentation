---
title: "Live Session Quick Reference"
description: A short Game Master checklist for operating a live Room Session.
---

## Before players enter

- Correct Room and Game Master selected
- Live View open on the player-facing display
- Starting time and reported Clues checked
- First Puzzle and required media available
- Room reset to its starting state

## Start

1. Select **Start**.
2. Confirm the Live View timer moves.

## During the game

- Select the current Puzzle before choosing a Clue.
- Use prepared Clues before writing a custom message.
- Check the Session Log before resending content; use its filter when you need to isolate one type of action.
- Mark tracked Puzzles complete only after the players solve them.
- Adjust time or reported Clues only when the Room Session requires it.

## Finish

- Success: select **Complete Room**.
- Failure: allow timer expiration.
- Confirm the final Game Master and Session details.
- Save once and wait for confirmation.
- Reset the Room before the next group.

If something does not work, open [Troubleshoot a Live Session](/run-a-session/troubleshoot-a-live-session).
