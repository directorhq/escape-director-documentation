A short checklist for Game Masters who already know the Room Dashboard. For the full walkthrough, see [Run a live session](/run-a-session/run-a-live-session).

## Before players enter

- The right Room and Game Master are selected.
- Live View is open on the player screen.
- The starting time and Clue count are right.
- The first Puzzle and its media are ready.
- The Room is reset to its starting state.

## Start

1. Select **Start**.
2. Check that the Live View timer is counting down.

## During the game

- Select the current Puzzle before choosing a Clue.
- Send a prepared Clue before writing a custom message.
- Check the Session Log before sending something again. Its filter shows one type of action at a time.
- Mark a Puzzle complete only after players solve it.
- Change the time or Clue count only when the game needs it.

## Finish

- If players escape, select **Complete Room**.
- If they don't, let the timer run out.
- Check the Game Master and Session details.
- Save once and wait for the confirmation.
- Reset the Room before the next group.

If something isn't working, see [Troubleshoot a live session](/run-a-session/troubleshoot-a-live-session).
