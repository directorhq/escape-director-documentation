# Escape Director help center

The customer guides published at
[docs.escapedirector.com](https://docs.escapedirector.com), built by Mintlify
from `main`.

- [`AGENTS.md`](AGENTS.md): how to work on the guides.
- [`docs.json`](docs.json): navigation, branding and redirects.
- [`docs/content-design.md`](docs/content-design.md): voice and style.

Check a change with `node scripts/validate-docs.mjs`, and preview it with
`npx mint dev`.
