Leaderboards rank the teams that escaped a Room and show them on a lobby
screen. Open **Leaderboards** in the app's side menu.

## Review rankings

Choose a **Room** and a **Period**: **All time**, **Today**, **This week**, or
**This month**. If you have more than one Location, the Room list shows the
Location picked at the top of the app.

<Frame caption="The Leaderboard ranks successful games in the chosen period, leaving out excluded ones.">
  <img src="/images/leaderboards.png" alt="Leaderboard for Sublevel 13 with gold, gold and bronze places for a tie, each team's time left and Clue count, and the Room and Period pickers" />
</Frame>

Teams rank by time left. If the Room tracks Clues, fewer Clues break a tie. If
it doesn't, equal times stay tied and there is no Clues column. Teams that
still tie share a place. Failed games aren't ranked. The list always shows
ranking order, 25 teams to a page.

## Correct a leaderboard entry

Use a row's edit action to correct the team name, or select **Exclude from
public leaderboards**. The team name is public, so keep private notes in Room
Statistics. To see entries you've removed, select **Show excluded**.

## Set up the lobby screen

Select **Display settings** to set up what the public lobby screen shows.

<Frame caption="You edit a draft next to its preview. The public Leaderboard keeps showing the last published version.">
  <img src="/images/leaderboard-settings.png" alt="Leaderboard Settings showing live publication status, Identity and Rooms controls, and a 1920 by 1080 Draft preview" />
</Frame>

1. **Identity:** set the title, optional subtitle, and logo.
2. **Rooms:** add Rooms and drag them into order.
3. **Standings:** choose how many teams to show and the ranking period. Rank,
   team, time, and Clues always show; turn on **Players** and **Date** in the
   table preview.
4. **Appearance:** choose the default background, any per-Room backgrounds, and
   the color used when there is no image.
5. Check the **Draft preview**. To match your lobby screen, type its width and
   height in the preview header, such as 1080 × 1920 for a screen on its side.
   This only changes the preview.

Changes save to a draft. The public Leaderboard changes only when you select
**Publish** or **Publish changes**. To throw away the draft, select **Reset to
published**. After publishing, open **View live** on the lobby screen to check
it.

## Show a Leaderboard at each Location

If you have more than one Location, each one can have its own Leaderboard with
its own public link. Pick a Location at the top of the app, then select
**Display settings** to set up that Location's board. Pick **All Locations** to
set up a board that can show Rooms from every site.

| Board | Rooms it can show | Who can set it up |
| --- | --- | --- |
| A Location's board | Only that Location's Rooms | The owner, and Managers with Room editing for that Location |
| All Locations board | Rooms from any Location | The owner, and Managers with Room editing for every Location |

A Room Station opens its own Location's board from **Leaderboards** with
**Open Leaderboard**. If you move a Room to another Location, it leaves the old
Location's board, so add it to the new one.
