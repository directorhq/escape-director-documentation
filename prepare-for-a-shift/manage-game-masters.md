# Manage Game Masters

Use this guide when a staff member joins, changes display name, or should no longer be selectable for new Room Sessions.

## Open Game Master management

1. Open any Room Dashboard.
2. Open the **Game Master** selector.
3. Choose **Manage Game Masters…**.

## Maintain the list

- Add one profile for each person who runs Rooms.
- Use a display name staff can recognize quickly.
- Rename the profile when the staff-facing name changes.
- Archive a profile that should no longer be chosen for new Room Sessions.

Archived profiles remain part of historical Room Session attribution but stay out of the normal active list.

## You're ready when...

Every Game Master working the shift appears once in the active selector and former staff is archived.
