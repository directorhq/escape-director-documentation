# Manage Game Masters

Game Master Profiles are the names Game Masters choose for each Room Session;
they don't sign in with their own accounts. Manage them from any Room Dashboard
in **Game Master → Manage Game Masters…**.

- Add one profile for each person who runs Rooms, with a name staff recognize.
- Rename a profile when the person's name changes. Older Room Sessions may keep
  the earlier name.
- Archive a profile that should no longer be chosen. Past Room Sessions keep it,
  but it leaves the active list.
