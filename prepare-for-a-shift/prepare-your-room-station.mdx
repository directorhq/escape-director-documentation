Use this checklist on the computer that will run the Room.

## Supported setup

Run each Room from one Windows or Mac computer, using Google Chrome or Microsoft Edge. The Room Dashboard and Live View can be separate windows on that computer, with Live View on the players' screen.

## Sign in the Room Station

The computer can sign in as you, or on its own as a Room Station. A Room
Station needs no password typed on it, runs games for one Location, and stays
locked until an owner or Manager unlocks it. Games keep running either way. To
set one up, see
[Add Managers and Room Stations](/account-and-help/add-managers-and-room-stations#set-up-a-room-station).

## Before guests arrive

1. Open **All Rooms**, choose the Room, and select the Game Master who will run
   the next group.
2. Select **Open Live View** and place it on the player-facing display. Keep the
   Room Dashboard on the Game Master's screen.
3. Check the starting time and reported Clue count.
4. Select a Puzzle and confirm its answer, description, and Clues are present.
5. Open the **Audio mixer** and test required audio at a safe volume.
6. Check any images or videos needed early in the game.
7. Select **Reset Room** if a previous test or game changed the state.

## Check offline readiness when required

Open the Room once while you're online. In **All Rooms**, wait until its card shows **Offline ready until** a date and time before you rely on it without an internet connection. A Room is ready offline only in the browser where you opened it. If you change the Room, open it again while online so the newest version is ready.

Open **Account Settings → This browser** to confirm when offline access expires and which Rooms are downloaded to this browser.
