A Room Station is the computer that runs a Room during games. Run this checklist on it before the first group of the day.

## What you need

Run each Room from one Windows or Mac computer, using Google Chrome or Microsoft Edge. The Room Dashboard and Live View can be separate windows on that computer, with Live View on the players' screen.

## Sign in the Room Station

The computer can sign in with your account, or on its own as a Room Station.
A Room Station needs no password typed on it, runs games for one Location, and
stays locked until an owner or Manager unlocks it. Games keep running either
way. To set one up, see
[Add Managers and Room Stations](/account-and-help/add-managers-and-room-stations#set-up-a-room-station).

## Before guests arrive

1. Open **All Rooms**, choose the Room, and select the Game Master who will run
   the next group.
2. Select **Open Live View** and move it to the player screen. Keep the Room
   Dashboard on the Game Master's screen.
3. Check the starting time and Clue count.
4. Select a Puzzle and check that its answer, description, and Clues are there.
5. Open the **Audio mixer** and test the Room's audio at a safe volume.
6. Check any images or videos the game needs early on.
7. If a test or earlier game changed anything, select **Reset Room**.

## Check that the Room is ready offline

Do this if the Room must keep running when the internet drops.

1. Open the Room once while you're online.
2. In **All Rooms**, wait until the Room's card shows **Offline ready until** a date and time.

A Room is ready offline only in the browser where you opened it. After you change the Room, open it again while online so the newest version is ready.

To see when offline access expires and which Rooms this browser has downloaded, open **Account Settings → This browser**.
