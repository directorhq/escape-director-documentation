A Game Master Profile is the name a Game Master picks for each Room Session.
Game Masters don't sign in with their own accounts. Manage profiles from any
Room Dashboard in **Game Master → Manage Game Masters…**.

| To… | Do this | What happens to past games |
| --- | --- | --- |
| Add someone who runs Rooms | Add a profile with a name staff recognize | — |
| Change someone's name | Rename the profile | Older Room Sessions may keep the earlier name |
| Stop someone from being picked | Archive the profile | Past Room Sessions keep the name; it leaves the active list |

Analytics uses these names to compare Game Masters, so keep one profile per
person.
